## 업무 센터

[`center.html`](center.html) — 이 저장소의 실무 도구를 업무 영역별 탭으로 모은 시작 화면입니다.
검색, 즐겨찾기, 최근 사용 기록을 지원하고, **편집** 버튼으로 탭과 카드를 직접 추가·수정·정렬할 수 있습니다.
구성은 브라우저에 저장되며, 내보내기/가져오기(JSON)로 다른 PC에 옮길 수 있습니다.

| 탭 | 도구 |
| --- | --- |
| 회계·행정 | 예산 사용 현황 · 예산 산출 계산기 · 프로그램 예산표 · 회의 출석부 |
| 정신건강정보 | 정신과 진단코드 검색기 · 입원유형 판단 안내표 · 학교 밖 나침반 |
| 상담 | 상담 통합 입력지 · 집중력 킵 |
| 사업 | 사회성 프로그램 기획 · 진행절차 일정표 생성기 |
